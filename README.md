# 🎬 Projector

Projector is a movie discovery web application built with React.js and the TMDB API.

## ✨ Features

- 🎬 Browse popular movies
- 🔎 Search for movies
- 📄 View movie details
- ❤️ Add movies to a watchlist
- 🗑️ Remove movies from the watchlist
- ⭐ Rate movies and leave feedback
- 🌐 Switch between English and Arabic
- ↔️ Support RTL layout for Arabic
- 💾 Store watchlist and feedback using localStorage

## 🛠️ Technologies

- React.js
- JavaScript
- React Router
- TMDB API
- HTML
- CSS
- Vite
- LocalStorage
